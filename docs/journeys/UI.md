
# Agent Center 配色规范

## 1. 品牌主色

表格

| 用途       | 色值                   | 说明                                    |
| ---------- | ---------------------- | --------------------------------------- |
| 主品牌红   | `#E6212A`            | 主按钮、选中态、重点操作、侧边高亮、CTA |
| 红‑橙渐变 | `#E6212A → #F06A48` | 推荐卡片主按钮，增强层次感              |
| 辅助橙     | `#F27022`            | 重点推荐业务按钮，次级行动色            |

## 2. 背景色

表格

| 用途       | 色值        | 说明                               |
| ---------- | ----------- | ---------------------------------- |
| 页面底色   | `#FCF9FA` | 全局页面背景，带低饱和粉紫弥散装饰 |
| 卡片容器   | `#FFFFFF` | Agent 卡片、内容模块白底           |
| 侧边栏选中 | `#FCE8EB` | 导航激活背景，主色低饱和变体       |

## 3. 文字色

表格

| 用途          | 色值        | 说明                   |
| ------------- | ----------- | ---------------------- |
| 标题 / 强文本 | `#1A1A1A` | 模块标题、Agent 名称   |
| 正文描述      | `#555555` | 卡片简介、说明文本     |
| 辅助标签      | `#888888` | 统计数字、次要备注信息 |
| 按钮文字      | `#FFFFFF` | 红色 / 橙色按钮内文字  |

## 4. 装饰 & 图标

- 功能图标：主图标使用品牌红，次要图标 `#555555`
- 背景装饰：低透明度淡粉、浅紫散点，仅做氛围，不干扰内容阅读
- 分割方式：不使用实线分割，依靠底色 + 圆角完成区块区分

## 5. 使用规则

1. 主红色用于绝大多数「发起对话」操作按钮；重点推荐项使用橙色做视觉区分。
2. 所有彩色均派生自红色系，禁止引入无关杂色，保持页面统一。
3. 文字与背景对比度满足 B 端阅读标准。
4. 背景装饰元素透明度不宜过高，避免干扰业务信息阅读。
